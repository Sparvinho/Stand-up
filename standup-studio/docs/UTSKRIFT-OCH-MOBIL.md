# Utskrift av minneslappar och mobilnavigering

## Utskrift

1. Öppna en sparad setlista som har minneslappar.
2. Klicka på **Skriv ut A6-lappar** (bredvid **Fusklapp**).
3. I webbläsarens utskriftsdialog: välj **A4**, **stående**, **100 % skala**, **marginaler: inga** (eller minsta möjliga marginaler).
4. Varje A4 innehåller fyra A6-lappar i 2 × 2-rutnät. Klipp längs de streckade linjerna.
5. För fler än fyra lappar skapas flera A4-sidor.

Om skrivaren inte stödjer kant-till-kant kan yttersta millimetrarna klippas. Använd vid behov PDF-utskrift först och kontrollera resultatet, eller välj skrivardrivrutinens passande utskriftsläge.

## Mobil

Överst finns flikarna **Setlista**, **Bibliotek** och **Sparade**:

- **Sparade**: öppna ett existerande set eller börja med en ny setlista. När du öppnar ett sparat set växlar mobilen till Setlista.
- **Setlista**: se och redigera det pågående setet; repetera, skriva ut och starta gig.
- **Bibliotek**: sök och lägg till skämt. Gå tillbaka till Setlista för att kontrollera ordningen.

På datorn fungerar de tre sektionerna som tidigare.
